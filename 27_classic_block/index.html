Classical Block Breaker

ブロックの うしろに
音楽室の しょうぞう画が かくれているよ。
名曲を 聞きながら ぜんぶ くずすと、
曲の 名前と つくった 人が わかる。
ステージの 形は あそぶたびに かわるよ。

アイテム（バーで とろう）

    ブロック

    • 1ふつう　1回で こわれる
    • 2かたい　2回で こわれる
    • 3てつ　3回で こわれる
    • ♪おんぷ　かならず アイテムが 出る
    • ✹ばくだん　まわりも いっしょに こわす
    • ◆こわれない　ほかを ぜんぶ くずすと きえる

    こつ：ブロックの すき間や 細い 通路に ボールを 入れて、ブロックの 上に のせると、ボールが 上で はねまわって 一気に くずれるよ。

    うごかしかた：ゆびや マウスで 左右に うごかす（キーボードなら ← →）。タップか スペースで ボールを うつ。

    絵と 音について

    しょうぞう画は、どれも 著作権の きれた 絵と 写真（パブリックドメイン）を ウィキメディア・コモンズ から かりて、顔のまわりを 切りぬいたものです。えがいた人と 年は、それぞれの しょうかいに 書いてあります。

    曲は、ブラウザの中で 音を 合成して ならしています（録音ではありません）。音の ならびは、Mutopia Project の 楽譜データ（7曲。うち2曲は CC BY-SA 3.0、ほかは パブリックドメイン）から 曲の はじめの部分を とりだしたものと、Piano Letter Notes の 音名の譜で たしかめたもの（3曲）です。曲の 名前は、クリアすると わかります。

    ざんねん！
