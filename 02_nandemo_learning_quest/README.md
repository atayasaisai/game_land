# なんでもラーニングクエスト

問題をかかげたモンスターが1秒に1歩ずつお城にせまってくる。こたえを選んで倒す学習ゲーム。
**1つのエンジン＋問題パックの差し替え**という作りで、いまは「せかいの国旗」パックが入っています。

## 開発するとき

`index.html` は `packs/flags.js` と画像フォルダを相対パスで読みます。
ブラウザによっては `file://` 直開きで相対パスの読み込みが止まるので、簡易サーバー経由が確実です。

```bash
cd 02_nandemo_learning_quest && python3 -m http.server 8000
```

→ ブラウザで http://localhost:8000/

## 人に渡すとき（1ファイル版）

```bash
python3 build-single.py
```

`dist/なんでもラーニングクエスト.html` ができます。画像33枚と問題パックを
data URI として中に埋め込んだ**完全に自己完結した1ファイル**（約4.8MB）で、
これだけを送ればダブルクリックで遊べます。ほかのファイルは要りません。

- 外に取りにいくのは Google Fonts だけ。ネットが無くてもヒラギノ丸ゴ等に落ちて表示されます
- メールが `.html` の添付をはじく場合があるので、同じ場所の `.zip`（約3.6MB）を使ってください
- **中身を直すときは `index.html` のほうを編集して、ビルドし直してください**

## 遊びかた

1. こたえる種類（**国の名前** / **しゅと**）と、むずかしさ（やさしい／ふつう／むずかしい／ぜんぶ／にがてだけ）を選ぶ
2. 1ステージ12問。いちばん左（お城に近い）モンスターが相手
3. 正解するとそのモンスターが爆発。5連続で大砲ポーズ
4. 城のハート3つがなくなるとおしまい

## とくてん

**お城までの のこり歩数 × 10点。**遠くで倒すほど高くなります（最大120点、ぎりぎりで10点）。

- 各モンスターの**いまの点数が、その国旗の上のふだに出ています**。近づくにつれて数字が減っていくので、
  「早く答えるほど得」が目で見えます
- まちがえると敵が2歩すすむので、**点数も20点ぶん下がります**（命は減りません）
- 正解すると、ふだの数字が大きくふくらんでから、画面左上の総得点へ吸い込まれます
- さいこう記録は `nlq_best_<packId>` に端末ごとに残り、更新すると「しんきろく！」が出ます
- 結果の「いっぱつ正解」は**一度もまちがえずに倒した問題の割合**です
  （倒した数だとクリア時は必ず100%になってしまうため）

## 学習のしくみ

ドリルとの違いは、**まちがいを資源にしている**ところです。

| ゲームの中 | 現実では |
|---|---|
| モンスター | まだ覚えていない問題 |
| 掲げている旗 | 問いそのもの |
| こうげき | こたえる |
| お城まで行かれる | 覚えないまま流れた |
| にがてな国旗 | 自分のつまずきの一覧 |

- まちがえた／通してしまった問題は**そのステージ中にもう一度出る**（最大2回まで再出題）
- さらに `localStorage` に残り、次回「にがてだけ」で遊べる
- **一発で正解したときだけ**にがてリストから外れる
- まちがえた選択肢は消えるので、残りから選び直せる（ばつは2歩すすむこと）

## ファイル

- `index.html` — エンジン（戦場の描画・進行・こたえ合わせ・記録）
- `packs/flags.js` — 問題パック「せかいの国旗」。36か国の国旗を**すべてSVGで自前で描画**
- `mon/` `hero/` `boom/` `congrats.jpg` — 借金退治クエストから流用した画像素材

## 問題パックを増やすには

`packs/` に同じ形のファイルを足して、`index.html` の `PACKLIST` に登録するだけです。

```js
window.PACKS.myPack = {
  id:"kuku", title:"さんすう ▸ 九九", subject:"さんすう",
  ask:"こたえは？", mode:"answer",
  items:[
    { key:"7x8", q:"7 × 8", a:"56", sub:"", lv:1, reg:"かけ算" },
    ...
  ]
};
```

- `q` は文字列でもSVGでも可（国旗パックはSVGを入れています）
- `reg` は**まぎらわしい選択肢を同じグループから選ぶ**ために使います（国旗では地域）
- `lv` は 1=やさしい 2=ふつう 3=むずかしい。各12問ずつにしておくと1ステージにちょうど収まります
- `sub` はこたえ合わせのときに添える補足（首都パックでは国名）

## 国旗について

36か国すべて外部画像を使わず手描きのSVGです。
**ブラジル・スペイン・ポルトガル・メキシコ・みなみアフリカ**の中央の紋章は簡略化しています
（データ側で `emblem:true`、タイトル画面にも注記あり）。
みなみアフリカの首都は3つあるため、行政の首都プレトリアを答えにして注記をつけています。
